Counts & Alarm Toggle

Counts and Alarm Toggle mentions three rectangular boxes.

  • The red rectangular box represents the status that the latest value of devices and pumps is greater than maximum threshold values and the number represents the count number of devices and pumps whose latest values are greater than maximum threshold values.
  • The yellow rectangular box represents the status that the latest value of devices and pumps is less than minimum threshold values and the number represents the count number of devices and pumps whose latest values are less than minimum threshold values.
  • Sound icon transmits the alert sound when the latest value of devices and pumps is greater than maximum threshold values. It can be muted to stop the sound.
