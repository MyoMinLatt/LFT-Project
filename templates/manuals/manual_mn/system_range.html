Custom Range

Custom Range is to limit the period or range of data that you are interesting instead of displaying all data in the graph.

Figure 26. Setting Custom Range

The period or range of time can be set by selecting start and end date, and the default graph can be reset. In key-value table, Current value is the value at current time of Today but Mean, Minimum and Maximum values are average, the smallest and the greatest value based on the data during the selected range of time.
