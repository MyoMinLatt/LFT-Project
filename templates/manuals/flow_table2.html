2nd Key-value Table

"2nd Key-value Table” means the key-value table appear when you customize the detail time and check the data of any device and pump. The data at any minute, hour, day, month within project can be customized and checked. (Figure-8).

Figure 8. 2nd Key-value table with present data

Date : The date can be selected in “Calendar”.
Time : Detail time, minutes and hour, that you want to check post data can be selected above “Calendar”.
Value : It means the value of devices or pumps at the time (detail hour and minute) on the selected date that you want to curiously know. In case, the value cannot be seen if there is no past data at exact minute that you selected (Figure 9)

Figure 9. 2nd Key-value table with absent data

Avg : It means the average value of devices or pumps on the selected date that you want to curiously know.
Max : It means the maximum value of devices or pumps on the selected date that you want to curiously know.
Min : It means the minimum value of devices or pumps on the selected date that you want to curiously know.
