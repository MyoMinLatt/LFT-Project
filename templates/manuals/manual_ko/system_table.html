Key-value Table of Graph

Key-value Table is shown under the graph representing four values of Today in each column.

  • Current value means the latest live streamed value of respective devices or pump Today.
  • Mean value means average value of respective devices or pump derived from calculation of all values recorded up to current time Today.
  • Minimum value means the smallest value of respective devices or pump derived among all values recorded up to current time Today.
  • Maximum value means the greatest value of respective devices or pump derived among all values recorded up to current time Today.
