Input Browser

In such window or browser, the dropped boxes of essential required variables with names such as X, Y, Cov. and Control, etc and buttons such as summary and plot are arranged. The variable can be dropped down into the essential required variable dropped boxes by dragging the variable from the variable buttons under button of parameter. The explanation of each feature in input browser are as follow;

Labels Features Meaning Purposes
X Data dropped box Dependent variables To drag and drop single or multiple dependent variables as necessary
Y Data dropped box Independent variables To drag and drop single or multiple independent variables as necessary
Cov. Data dropped box Covariate variables To drag and drop single or multiple covariate variables as necessary
Control Data dropped box Control variables To drag and drop single or multiple control variables as necessary
Summary Popup button Summary of results To print summary of results according to statistical methods after all inputs as necessary.
Plots Popup button Plots of result To print plots of results according to statistical methods
