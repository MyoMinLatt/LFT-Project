Setting Threshold

Thresholds is a private button to set minimum and maximum threshold values of devices and pumps. Password is needed to set threshold values (Figure 13). Devices and pumps are hidden under Threshold Button. If Password is correct, the hidden list of devices and pumps will be dropped down and thresholds can be set (Figure 14).
